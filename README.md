# 留方（Shakashaka）

一个纯前端、可离线运行的 **Shakashaka（留方）** 逻辑谜题：在白格中放置黑色直角三角形，
把所有「没放三角形的白格」切成矩形；黑格上的数字表示其上下左右四格中的三角形数量。

- 技术栈：TypeScript + Vite，无框架、无外部资源（SVG 渲染 + Web Audio 合成音效）
- 内置 6 道题：全部 **唯一解**，且能 **纯规则逻辑推完**（数字约束 → 矩形约束 → 2×2 凸角 → 共享白格，反证兜底）
- 支持实时校验、错误高亮、求解、提示一格、逻辑解题回放、撤销重做、自定义题板
- 自定义题库/进度保存在项目内 `data/`（开发服务器）或浏览器 localStorage（静态预览）

## 规则

1. 棋盘由黑格（题面给定）和白格组成。
2. 在每个白格里，可以放一个黑色直角三角形，或留空。三角形有四种朝向：
   左上、右上、左下、右下（直角贴在哪一个角）。
3. **所有没放三角形的白格** 必须两两相连成若干个 **矩形区域**（每个四连通白区都必须是一个
   完整的矩形，不能是 L 形、凹形或带洞形状）。
4. 黑格上可能有数字 `0–4`：它等于该黑格 **上下左右四个相邻格** 中三角形的数量。
5. 题目保证 **唯一解**。注意：三角形朝向不影响任何规则，唯一解指「哪些格子放三角形」唯一。

## 逻辑推理定式（安全规则）

逻辑解题器按下面的顺序做定点推理；每一条都只做「必然」删减，可证明、不会引入错误格子：

| 编号 | 定式 | 说明 |
| --- | --- | --- |
| R1 | 数字约束 | 数字 = 四周三角形数量。能放三角的格恰好够 → 都放三角；需要留空的格恰好够 → 都留空；数字 > 白邻居数直接判矛盾 |
| R2 | 矩形约束 | 留空白格连通块的外接矩形内部必须全部留空；已补成矩形后，某一侧无法整排外扩 → 紧贴该侧的一排格必须放三角 |
| R3 | 2×2 凸角 | **任意 2×2 内不能恰好有 3 格留空**。三格留空必在同一块矩形里，外接框就是这 2×2；第 4 格若是三角/黑格就落在矩形内却不是留空 → 矛盾。于是「2 格必留空 + 1 格必三角」可推出第 4 格必三角 |
| R4 | 共享白格 | 对角相邻的两个数字格共享 2 个白格邻居。枚举共享格的三角/留空分配，用两个数字的缺额可行性判断；在所有可行分配里取值一致的共享格即可确定 |
| R5 | 反证 | 逐格试填「留空 / 三角」，若其中一种让传播立刻矛盾则排除（R1–R4 推不动时才使用） |
| R6 | 回溯兜底 | 仍推不完时用求解器补完，回放中标注「回溯试探」（内置题不会走到这一步） |

> 说明：`2×2 全留空`（一整块 2×2 矩形）和 `2×2 全三角`（例如被黑格/边界围住的四格三角块）在本作的简化模型下**都可以合法**，因此没有加入「2×2 全黑/全白禁止」这类规则；加入会错误地排除真解。R3 只禁止「恰好 3 格留空」，这是由矩形凸性可证明的唯一局部 2×2 限制。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键 | 循环切换：空 → 左上 → 右上 → 左下 → 右下 → 空 |
| 右键 | 清除该格三角形 |
| 按住左键拖拽 | 连续涂写 |
| 方向键 | 移动键盘光标（跳过黑格） |
| 空格 | 循环切换当前格的三角形朝向 |
| 数字键 `1`–`4` | 直接设为对应朝向（1 左上 / 2 右上 / 3 左下 / 4 右下） |
| `0` / `Backspace` / `Delete` | 清空当前格 |
| `Z` / `Shift+Z` | 撤销 / 重做 |
| `C` | 检查 |
| `L` | 逻辑解题 / 停止回放；回放中 `P` 暂停/继续 |
| `R` | 随机抽题 |
| `+` / `−` / 滚轮 | 放大 / 缩小画布 |
| `Esc` | 清空盘面 |

## 自定义题板

左侧「自定义」按钮打开编辑器（宽高各 4–30）：

- 单元格点击循环：`空 → 黑(■) → 黑0 → 黑1 → 黑2 → 黑3 → 黑4 → 空`；
- 键盘：`0` = 白格，`1`–`4` = 黑格带同数数字，`5` = 黑格无数字，`.`/`退格` 清空；
  方向键移动光标；
- **载入题板**：把当前编辑的盘面载入游戏并存入题库；
- **保存到题库**：存入 `data/library.json`（刷新后仍在左侧列表里）；
- **求解**：求解并校验「是否恰好一解」，状态栏会显示 `唯一解 ✔` 或 `多解（至少 2 组）`；
- **逻辑解题**：对当前自定义盘面做规则推理回放；
- 题库列表中的自定义题带 **编辑** 与 **删除** 按钮（删除需再点一次确认）。

## 启动

```bash
cd 留方
npm install
npm run dev        # 开发服务器，默认 http://127.0.0.1:5213
# 或
npm start          # 启动并自动打开浏览器
```

端口 **5213** 定义在 `package.json` 的 `puzzle.port`，`vite.config.ts`、`scripts/dev.mjs`、
`scripts/ui-check.mjs` 统一从这里读取。

静态构建与预览：

```bash
npm run build      # tsc --noEmit && vite build
npm run preview    # 预览 dist/（端口同样来自 package.json）
```

## 测试

```bash
npm run check      # 题库审计：6 题唯一解、参考解合法、纯逻辑可推完、编解码/存档往返
npm run ui-check   # Playwright 冒烟测试（先启动 dev server，端口 5213）
```

`npm run check` 直接在 Node 里 import `src/game/audit.ts` 与求解器（Node 24 原生 TS
type-stripping），无需浏览器；截图输出到 `output/playwright/`。审计表会列出每题的
**反证次数 / 回溯节点 / 未定格数**，并在末尾汇总「反证合计 · 回溯节点合计 · 纯规则题数」，
用来观察新定式是否真的减少了反证与回溯。

## 图片导入题库（识图 CLI）

```bash
npm run import-image -- month.png                # 识别并预览（不写入）
npm run import-image -- month.png --verify       # 额外求解 / 唯一性检查（大盘面会超时警告）
npm run import-image -- month.png --append       # 写入 src/game/imported-puzzles.ts
npm run import-image -- month.png --json out.json  # 导出识别结果
```

- 全自动识图：Playwright + 本机 Edge 取像素 → 网格线投影定位 n×n 格 →
  格心区域判断黑格/白格 → 黑格里白字（0–4）连通域提取 → 字形聚类 + 多字体多字号模板匹配。
- 结构校验：数字不得超过其相邻白格数；仍不确定时用 `--map 簇号=数字` 覆盖字形簇判读，
  或 `--fix "列,行=值"`（值写 `#` 或 0–4）覆盖单格。
- 导入题写入 `src/game/imported-puzzles.ts`，`npm run gen` 不会覆盖；游戏启动时会与内置题一起加载。
- 限制：`--verify` 对 50×50 这类大盘面基本必然超时（只警告）；未带参考解时「显示解 / 提示一格」
  依赖求解器现场计算，大盘面可能很慢。

## 实现要点

- **状态**：每格三角形朝向 `0=空 / 1..4=左上/右上/左下/右下`；黑格在题面 `board` 中编码，
  状态里同时保存一份题面副本，使左键/右键/校验在只有 `state` 的场合也能识别黑格。
- **校验**：数字计数 + 白区四连通块外接矩形面积比较；错误格在 SVG 上红色高亮，
  白区按连通块着色，矩形是否规整一眼可见。
- **求解器**：把「朝向」折叠成「留空 / 三角形」两类，用域传播做前向剪枝再回溯；
  `countSolutions` 数到 2 组即可判断唯一性。
- **逻辑解题**：先数字约束、再矩形约束（外接矩形补完、已完成矩形无法整排外扩时紧贴格必须放三角），
  再用 2×2 凸角定式与对角数字共享白格的弧一致继续推，最后才逐格反证、必要时回溯兜底。
  内置题现在多数已能只靠定式推完（`npm run check` 会显示每题反证次数）。
  推理的工作域从**当前盘面**开始：玩家已放置的三角形（任意朝向）视为已知三角形，未知格保持全部候选；
  回放帧的 `from` 取当前值，不会覆盖玩家已填内容。
- **题库**：`npm run gen` 随机黑格布局 → 求解 → 由解反推数字 → 唯一解 + 纯逻辑校验 →
  贪心把多余黑格还原为白格。生成结果写入 `src/game/puzzles-data.ts`。

## 已知限制

- 矩形约束的传播是必要条件剪枝，极少数自定义题可能无法只靠规则推完（逻辑解题会标注
  「回溯试探」并给出完整解）。内置题与新加固测试集均可纯规则推完。
- 反证仍有预算上限（12000 次试探 / 60 轮），超预算后转回溯兜底；自定义 30×30 大盘面可能触发。
- 自定义题板的唯一解校验对 30×30 大棋盘可能搜索超时，此时会提示「求解超时」。
- 三角形朝向不影响规则，因此参考解中的朝向只是观感，不参与唯一性判定。
